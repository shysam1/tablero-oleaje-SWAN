================================================================================
  TABLERO DE OLEAJE — GUÍA DE INSTALACIÓN (WINDOWS)
================================================================================

Entrega revisada el 22 de septiembre de 2026. El ZIP contiene las correcciones
de la auditoría; el instalador histórico Tablero_Oleaje_Setup_1.0.1.exe no se
reemplazó y no incorpora automáticamente los cambios de esta carpeta.

REQUISITOS

- Windows de 64 bits y Python 3.11 o superior de 64 bits.
- La combinación comprobada en una instalación limpia es Windows x64 con
  Python 3.13. Sus dependencias están fijadas en requirements-windows-py313.lock.
- Microsoft Edge WebView2 Runtime para mostrar la ventana.
- Internet en la primera preparación para descargar las librerías.
- Espacio libre para el entorno Python y para los resultados de tus propios datos.

Python: https://www.python.org/downloads/
Instálalo para tu usuario y marca "Add python.exe to PATH" si aparece esa opción.
WebView2: https://developer.microsoft.com/microsoft-edge/webview2/

ABRIR LA ENTREGA ZIP

1. Extrae todo el ZIP a una carpeta donde tu usuario pueda escribir, por ejemplo
   Documentos. No ejecutes el .bat dentro de la vista comprimida del ZIP.
2. Abre iniciar_windows.bat.
3. Espera a que se cree .venv y se instalen las dependencias. Si se interrumpe,
   el siguiente inicio vuelve a intentar completar la preparación.
4. Las siguientes aperturas comprueban el entorno localmente; no necesitan
   internet para analizar archivos locales. ERA5 sí requiere conexión.

Crear Tablero.bat permite crear un acceso directo dentro de esta carpeta.

SI UTILIZAS UN INSTALADOR .EXE

El instalador per-user está configurado para instalar en:
  %LOCALAPPDATA%\Tablero de Oleaje
No requiere permisos de administrador. La versión histórica 1.0.1 debe probarse
por separado; esta revisión no realizó su instalación en otra cuenta Windows.
La app necesita Python y WebView2: el .exe no contiene un Python independiente.
Si aparece SmartScreen, comprueba la procedencia del instalador antes de abrirlo.

RESULTADOS Y REGISTROS

En la entrega ZIP: dentro de la carpeta extraída, en salidas\.
En la instalación per-user: %LOCALAPPDATA%\Tablero de Oleaje\salidas\.
Si el código no permite guardar resultados, la app utiliza esa carpeta de datos
del usuario. Para preparar .venv desde el ZIP, la carpeta extraída sí debe ser
escribible; muévela a Documentos si fuera necesario.

- Registro de preparación: salidas\install.log
- Registro de la ventana: salidas\app_web.log
- Preferencias: config.json. No se incluyen preferencias ni credenciales ajenas.

HERRAMIENTAS OPCIONALES

SWAN es necesario para ejecutar modelos, pero no para analizar archivos de
oleaje o resultados SWAN existentes. ffmpeg permite exportar MP4; si falta,
la aplicación puede generar una animación GIF mediante Pillow.
Las descargas ERA5 requieren credenciales CDS propias y aceptar las condiciones
del dataset en la cuenta correspondiente.

SI FALLA

- Python no disponible: instala una versión de 64 bits y vuelve a abrir.
- Fallo de descarga: revisa internet e install.log y vuelve a intentar.
- Entorno antiguo o movido que ya no funciona: cierra la app, renombra .venv
  como .venv_respaldo y vuelve a abrir para crear uno nuevo.
- Ventana que no abre: revisa app_web.log y la instalación de WebView2.
- Resultados o datos faltantes: conserva el archivo de entrada y el registro
  para diagnosticar el problema; no borres las salidas de otros trabajos.

DESINSTALAR

Si usaste el .exe, utiliza su acceso "Desinstalar Tablero de Oleaje" o la sección
Aplicaciones de Windows. El desinstalador conserva resultados y preferencias.
Si usaste el ZIP, cierra la aplicación y conserva salidas\ antes de retirar
la carpeta. Desinstalar Python global no es parte de retirar esta aplicación.
