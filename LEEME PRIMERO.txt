ESTA ENTREGA

Esta carpeta contiene la versión revisada en la auditoría del 22 de septiembre
de 2026. Extrae todo el ZIP antes de iniciar la aplicación.

La instalación de dependencias se comprobó en Windows x64 con Python 3.13,
partiendo de una copia sin entorno virtual. Necesitas Python de 64 bits,
WebView2 en Windows e internet la primera vez. No es una aplicación que incluya
su propio intérprete Python.

Los instaladores históricos .exe no fueron reemplazados. No debe suponerse que
Tablero_Oleaje_Setup_1.0.1.exe incluye las correcciones de este ZIP.
No se entrega ni se ha validado un nuevo DMG para macOS.

WINDOWS

1. Extrae la carpeta a una ubicación escribible, como Documentos.
2. Lee GUIAS DE USO/GUIA INSTALACION WINDOWS.txt.
3. Instala Python 3.11 o superior de 64 bits; Python 3.13 es la combinación
   comprobada y utiliza versiones de dependencias fijadas para Windows.
4. Haz doble clic en iniciar_windows.bat.
5. Espera a que termine la preparación; las siguientes aperturas reutilizan
   el entorno. Si la descarga falla, se reintenta en el próximo inicio.

Opcional: Crear Tablero.bat crea un acceso directo dentro de esta carpeta.

macOS — PENDIENTE DE VALIDACIÓN EN UN MAC REAL

Se incluyen scripts para macOS, pero esta auditoría no comprobó el inicio en
Intel ni Apple Silicon. Las guías de macOS son una referencia de preparación;
no demuestran que exista un DMG validado para esta entrega.

Para probar la carpeta con Python 3.11 o superior de 64 bits, abre Terminal:
  cd "/ruta/a/Tablero Oleaje"
  chmod +x iniciar_mac.command
  ./iniciar_mac.command

El registro de preparación queda en:
  ~/Library/Application Support/Tablero de Oleaje/install.log

DATOS Y FUNCIONES OPCIONALES

Los resultados quedan en salidas/ dentro de la carpeta extraída. Si esa ruta no
permite escritura, la aplicación utiliza la carpeta de datos de tu usuario.
Conserva tus resultados antes de mover o retirar la aplicación.

Analizar archivos locales no requiere cuenta CDS ni SWAN. Descargar ERA5
requiere internet y credenciales CDS propias. Ejecutar modelos requiere SWAN.
ffmpeg es opcional para MP4; si falta, puede exportarse una animación GIF.

La entrega no incluye datos personales, credenciales, config.json, resultados
previos ni el entorno Python del autor.

AYUDA

Revisa salidas/install.log si falla la preparación y salidas/app_web.log si falla
la ventana. En macOS, el registro de instalación usa la ruta indicada arriba.
Para información sobre cada operación, consulta las guías de uso de tu sistema.
